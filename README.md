# راهنمای راه‌اندازی ربات سیگنال (کاملاً رایگان)

## قدم ۱: ساخت ربات تلگرام
۱. توی تلگرام به **@BotFather** پیام بده
۲. دستور `/newbot` رو بزن، یه اسم و یوزرنیم بده
۳. یه توکن بهت میده شبیه این: `123456:ABC-DEF...` — نگهش دار (BOT_TOKEN)

## قدم ۲: پیدا کردن Chat ID خودت
۱. به ربات تازه‌ساخته‌ت یه پیام بده (مثلاً `/start`)
۲. توی مرورگر برو به این آدرس (به‌جای TOKEN توکن خودت رو بذار):
   `https://api.telegram.org/botTOKEN/getUpdates`
۳. عدد جلوی `"chat":{"id":` رو کپی کن — این CHAT_ID توئه

## قدم ۳: ساخت ریپازیتوری گیت‌هاب
۱. یه اکانت رایگان گیت‌هاب بساز (github.com) اگه نداری
۲. یه ریپازیتوری جدید بساز (می‌تونه Private باشه)
۳. همه فایل‌های این پوشه (bot_logic.py, watchlist.json, requirements.txt, .github/) رو توش آپلود کن

## قدم ۴: تنظیم رمزها (Secrets)
توی ریپازیتوری برو به: **Settings → Secrets and variables → Actions**

بخش **Secrets** (این‌ها مخفی می‌مونن):
- `BOT_TOKEN` = توکن ربات از قدم ۱
- `CHAT_ID` = عدد از قدم ۲

بخش **Variables**:
- `CAPITAL` = مثلاً `64`
- `RISK_PCT` = مثلاً `2`

## قدم ۵: روشن‌کردن Actions
برو به تب **Actions** توی ریپازیتوری، تایید کن که فعاله. از این به بعد هر ۱۵ دقیقه خودکار اجرا میشه.

## نحوه اضافه‌کردن سیگنال جدید
هر وقت BITFA (یا هر کانالی) یه ارز جدید معرفی کرد:
۱. توی گیت‌هاب فایل `watchlist.json` رو باز کن (روی قلم ✏️ بزن برای ویرایش)
۲. یه آیتم جدید مثل این اضافه کن:
```json
{
  "symbol": "SYMBOLUSDT",
  "signal_time": "2026-09-21 15:30",
  "status": "new"
}
```
۳. Commit کن. دفعه بعدی که ربات اجرا بشه (حداکثر ۱۵ دقیقه بعد)، خودش محاسبه می‌کنه و بهت پیام میده.

## نکته مهم
این ربات فقط **تحلیل و هشدار** میده، خودش معامله نمی‌کنه. خرید و فروش واقعی رو خودت دستی انجام میدی — این عمداً اینجوریه تا کنترل کامل دست خودت بمونه.
